# Synthetic scenario generator v1

`scenarios.json` freezes the six A18 scenario definitions and their source/DESIGN labels when this task lands; later parameter changes require the planned ADR process. `generator.ts` produces versioned, provenance-marked `DayBundle` logs and parallel true/observed cycle histories; the skipped-log case has one output for each A18 rate (0.1 and 0.2). This is fixture generation only: it does not implement prediction, backtesting, or clinical validation.

Generation requires an explicit unsigned 32-bit seed. Preview data defaults to the explicit seed 42. The fixed `2020-01-01` anchor is calendar placement only and can be replaced with a validated `LocalDate`. All arithmetic uses the landed LocalDate engine. HLC values use a fixed synthetic device id and deterministic ordering counters; `wallMs: 0` is synthetic metadata, not a clock read.

Sampling follows A18: stable means are uniform over 24–35 days, stable standard deviations are selected from 1, 2, 3, and 4 days, lengths are Gaussian rounded to whole days, and the irregular standard deviation is uniform over 5–9 days. The A18 outlier range does not specify how to select an increment, so this implementation samples integer increments uniformly over 8–14 days when its 5% event occurs. Drift uses the A18/TV-A2 example (28 days then 24 days, standard deviation 1). “Then the stable profile” in post-pill means 12 stable-profile cycles after its first two post-pill cycles. These interpretations are recorded rather than tuned against a future engine. Invalid non-positive rounded cycle lengths are rejected, not clamped or silently resampled.
