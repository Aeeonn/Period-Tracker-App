# ADR-0011: Orchestration on VS Code Copilot agents (replaces Pi, Herdr and tasks-axi)

- **Status:** Accepted (captain request, 2026-10-28). Supersedes the tooling parts of [ADR-0009](0009-agent-operating-model-on-firstmate.md). ADR-0009's policy (roles, routing rules, verification depth, fix-round limits, landing discipline) stays in force.
- **Context:** Pi can no longer sign in to GitHub Copilot because an organizational sign-in (Conditional Access) policy blocks it. Firstmate's spawn, supervision and backlog paths (`bin/fm-spawn.sh`, Herdr panes, `tasks-axi`, `bin/fm-merge-local.sh`) all assume Pi workers, so they cannot run. Copilot in VS Code still works and can launch custom-agent subagents. The captain asked for agents and skills that keep Firstmate's way of working, for a backlog inside the repository, and for files built around Herdr, Pi or Firstmate to be rewritten.
- **Decision:**
  - **Agents** ([`.github/agents/`](../../.github/agents/)): `flo-orchestrator` (first mate; the captain's chat), plus subagent crewmates `flo-builder` (ship), `flo-verifier` (independent `-verify`), `flo-researcher`, `flo-critic` and `flo-planner` (scouts). Worker agents cannot launch further subagents and never address the captain. The repository copy is the source of truth. [`tools/agent-ops/install-user-agents.sh`](../../tools/agent-ops/install-user-agents.sh) installs user-level copies for chats without a Flo workspace.
  - **Routing.** The five rules in `~/firstmate/config/crew-dispatch.json` map to agent defaults: Opus 5.5 for the verifier, critic and planner; GPT-6 Luna for the builder; GPT-6.1 Sol for the researcher. The documented per-task overrides are Opus for rule-2 or escalated builds, Luna for low-risk reviews, and Luna for a research task when recorded at dispatch (never a silent substitution). Effort is high at minimum: it is set in agent frontmatter and also passed explicitly at dispatch. Luna and Sol use the default context tier. The dispatch record in the backlog notes replaces Pi's `PI_*` startup check.
  - **Skills** ([`.agents/skills/`](../../.agents/skills/)): `flo-dispatch` (session start, routing, dispatch, supervision, correction rounds, captain etiquette), `flo-backlog`, `flo-worktree`, `flo-commit` and `flo-land`, plus the rewritten `task-brief` (with ship, verify and scout templates) and `verification-protocol`.
  - **Backlog.** [`docs/plan/backlog.md`](../plan/backlog.md), managed with `backlog.py`, replaces Firstmate's `tasks-axi` backlog for Flo. It was migrated from `backlog-import.md` and the Firstmate backlog and archive on 2026-10-28. The orchestrator commits backlog and progress-log updates directly on `main` as `chore(backlog): …` (captain decision, 2026-10-28; a narrow exception to "only integration tasks write `docs/progress.md`").
  - **Records stay private and outside the repository.** Briefs, notes and reports live in `~/firstmate/data/<task-id>/`, and status events in `~/firstmate/state/<task-id>.status`. This keeps verifier reports out of the reviewed source and lets Firstmate take over again.
  - **Isolation.** Each task gets its own treehouse-pool worktree, claimed with `git worktree lock` because treehouse cannot see Copilot workers. Builders use `fm/<task-id>` and verifiers use a detached laboratory at the exact SHA. Landing is a guarded fast-forward of the exact reviewed SHA, then a push of `main` only, after the remote URL and live head are checked (`land.sh`).
  - **Concurrency:** at most 6 live subagents (captain, 2026-10-28). **One orchestrator chat at a time.**
- **Consequences:**
  - No new dependency or service. The scripts use bash, git and the system `python3`. Policy is still enforced by discipline plus scripted guards, not a sandbox. Verifier isolation is **not enforced** (the captain approved ordinary review), so reports say so.
  - Subagents run in the orchestrator's VS Code session. A captain message can cancel running workers, so the orchestrator checks live workers after every captain message and resumes from preserved drafts.
  - Firstmate's `data/backlog.md` is frozen for Flo items. Its other projects and its own tooling are unchanged.
